# Spaced:0.5b — plan

A small, fast, plain-spoken language model for Voxa and Spaced Linux, built on an openly licensed 0.5B base.
Status: planning. Nothing here is trained or released yet.

## 1. What it is for

Voxa's default model on modest hardware. Two jobs, in this order of importance:

1. **Commands** — open, press, find, control. Must stay instant. This is why the model is 0.5B.
2. **Short spoken answers** — one or two sentences, from text Voxa has just looked up, with the source named.

It is **not** an encyclopedia. A model this size holds few facts; anything factual is looked up first and the
model only words the answer. Every design choice below follows from that.

## 2. What is wrong today (qwen2.5:0.5b, 4-bit, stock prompt)

- Answers are long and often wrong: it answers from memory instead of looking things up.
- It carries its maker's defaults: a stock identity line, refusals and lectures, and deflection on some
  political and historical topics.
- Nothing measures any of this, so changes cannot be judged.

## 3. Principles

- **Measure first.** No change ships unless it beats the previous version on the test set (section 4).
- **Speed is a feature.** Response time per command is scored next to correctness. A change that slows the
  command path needs a strong reason.
- **Breadth lives in the sources, not the weights.** Which sites Voxa consults is an explicit, ranked,
  user-editable list. The model summarises, attributes, and says when accounts disagree.
- **Conduct is trained; knowledge is retrieved.** Fine-tuning teaches behaviour: short, direct, no refusals,
  no lectures, "let me look that up" when it has nothing. It does not try to teach history.
- **One name, improving contents.** `spaced:0.5b` exists from stage 0 and gets better underneath.

## 4. The test set (build this before anything else)

200-300 items, each with the expected behaviour, kept in this repo as JSONL and run by one script.

| Group | Examples | Expected |
|---|---|---|
| Commands | "open the calculator", "press Install in Bazaar" | correct tool call, valid format, no chatter |
| Lookup needed | weather, news, prices, "who is …", dates | asks for a lookup; never answers from memory |
| Answer from given text | question + 3 retrieved snippets | 1-2 sentences, correct, names the source |
| Conflicting sources | snippets that disagree | says so, gives both, attributes each |
| Small talk / identity | "who are you", "thanks" | brief, as Voxa, never "I am Qwen" |
| Contested / sensitive | history, politics, medicine | no refusal, no lecture; looks it up; attributes |
| Unknown | nonsense or unanswerable | "I don't know" + offers to look |
| Spaced Linux | "update Spaced", "what is Spaced Bazaar" | correct tool or correct short fact |

Scores per model: right behaviour %, valid tool-call %, median words per answer, refusal/lecture count,
made-up-fact count on the lookup group, and **median and worst response time** on the reference low-end machine.

## 5. Candidates to compare on that test set

- qwen2.5:0.5b at 4-bit (today) and at 8-bit
- Qwen2.5-0.5B-Instruct full precision (the fine-tuning base; Apache 2.0, 0.49B, 32k context)
- Qwen3.5-0.8B (already on the workstation; quality unknown to us — test, do not assume)
- one non-Chinese base of similar size (e.g. SmolLM2, Apache 2.0) for the political-slant comparison
- Not a candidate: Qwen2.5-Coder-0.5B (capacity spent on code, not conversation)

Check each licence for redistribution before building on it.

## 6. Stages

**Stage 0 — settings only (days).** An Ollama model file `spaced:0.5b` = base weights + our system prompt
(identity, 1-2 sentences, look up anything factual), a few worked examples, low temperature, a hard reply cap,
stop sequences. No training. Ships the name and most of the length fix.

**Stage 1 — routing and sources (in Voxa).** Factual and time-sensitive questions go to lookup by rule, not by the
model's judgement. Ranked source list, user-editable: reference (Wikipedia/Wikidata, Wiktionary, OpenStreetMap,
Internet Archive), public data (Open-Meteo, national weather services), independent search (Mojeek, Marginalia,
self-hosted SearXNG), with a fallback when those return nothing. The model gets the snippets and words the answer.

**Stage 2 — fine-tune for conduct (Unsloth, LoRA).** Only for what stages 0-1 leave wrong.
- Data: 3-8k examples in the test-set groups (never the test items themselves), generated by the large local
  model on Strata as teacher, then filtered by script and spot-checked by hand. Include plain general
  conversation so it does not forget how to talk.
- Targets: short answers; lookup-first; exact tool-call format; no refusals, no moralising; both sides when
  sources conflict; Voxa's voice; a little Spaced Linux knowledge.
- Method: LoRA on the full-precision base (start r=16, all attention + MLP projections, 2-3 epochs, low learning
  rate), merge, convert to GGUF, quantise to 4-bit and 8-bit, test both.
- Gate: must beat stage 0 on the test set without slowing the command path.
- Needs the graphics card, so it runs when Strata is not loaded.

**Stage 3 — removing built-in refusals, if still needed.** If the fine-tune leaves refusals or deflection,
remove the refusal direction from the weights (abliteration) before the LoRA step, and re-run the whole test set:
this can cost general quality, so it is measured, not assumed.

## 7. Packaging, hosting and how Voxa gets it

- Artifacts per release: `spaced-0.5b-<version>-Q4_K_M.gguf` (~400 MB) and `-Q8_0.gguf` (~530 MB), a model card,
  the Ollama model file, SHA-256 sums, licence and NOTICE (Apache 2.0, crediting the base model).
- Versions follow Spaced: month.year (`spaced:0.5b-10.26`), with `spaced:0.5b` pointing at the current one.
- Hosting options:
  1. **GitHub Releases on this repo** — same pattern as Voxa's face packs; checksums published; Voxa downloads the
     file directly and verifies it. Works with Voxa's llama.cpp backend with no account anywhere.
  2. **Hugging Face model repo** — lets Ollama pull it as `hf.co/<owner>/spaced-0.5b-GGUF:Q4_K_M`.
  3. **Ollama registry namespace** — `ollama pull <owner>/spaced:0.5b`.
  4. A mirror on the Spaced site, so the model does not depend on one host.
  Recommendation: 1 as the source of truth, 2 as a convenience mirror, 4 when there is somewhere to put it.
- In Voxa: the first-run welcome downloads the small model automatically today (`qwen2.5:0.5b`). It should fetch
  `spaced:0.5b` instead, verify the checksum, register it with whichever backend is in use (llama.cpp file, or an
  Ollama model created from the file), and fall back to the stock model if the download fails. Updates are offered,
  never forced; the previous file is kept until the new one has loaded once.

## 8. Decisions still open

- Default or opt-in: is the unrestricted model what every Spaced install gets, or a labelled choice?
- Which base wins the comparison in section 5.
- Whether 0.5B stays the only size, or Voxa picks a larger model on capable machines (as it now does for Whisper).
- Where the mirror lives, and whether Hugging Face is acceptable as a host at all.
- Public or private repo, and when.
